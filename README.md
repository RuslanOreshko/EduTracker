# Зписоок задвань для проєкту

## backend

1. Порівняння двох викладачів. (+ за датою)
2. Пік навантаження викладача. (+ вибір, піковий день, піковий тиждень, піковий місяць)
3. Середній показник пар в робочий день. (+ можна додати вибір конкретного викладачу)
4. Додавання запланованих годин/зайнять (окрема бд, де зберігається посилання на конкретного викладача із предметом, до іншої бд із json).
5. Перегляд проценту виконаних зайнять, дивлячись на заплановані.
6. Вивід зайнять, які зилишились.
7. Добавити реєстрацію, та логінизацію. (Зайти можна тільки через пошту коледжу)
8. Додати JWT авторизацію.
9. Рейтинг найкращий викладачів за кількістю занять певного предмету, чи певної групи

## frontend

1. написати базу на `Vue`
2. написати якісь стилі `css`
3. написати розмітку `html`
